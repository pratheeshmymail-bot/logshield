# Security Policy

LogShield is a best-effort redaction utility and must not be treated as a complete secrets-management or data-loss-prevention solution.

- Do not report vulnerabilities with real credentials or private logs.
- Use synthetic examples when reproducing issues.
- Once the repository is published, use GitHub's private vulnerability reporting feature where available.
- Do not assume that a file is safe to share merely because LogShield processed it. Review the result manually.
