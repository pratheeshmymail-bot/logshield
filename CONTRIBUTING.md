# Contributing

Thanks for considering a contribution!

1. Open an issue describing the bug or proposed improvement.
2. Use synthetic test data only. Never commit real logs, credentials, tokens, or personal information.
3. Add or update tests for behaviour changes.
4. Run `python -m pytest` before submitting a pull request.
5. Keep the tool offline by default; new network features require an explicit design discussion.

By contributing, you agree that your contributions are provided under the repository's MIT licence.
